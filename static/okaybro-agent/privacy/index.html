okaybro agent: privacy policy

Last updated: 24 October 2026

This policy covers "okaybro agent", a private assistant operated by Chaitanya Keyal for his own use. It does not cover chaitanyakeyal.com itself.

Who uses it

Only its owner. It is not offered to the public, and only the owner's own Google accounts are connected to it.

What data it accesses

With the owner's consent, it reads and, when asked, writes data in the owner's Gmail, Calendar, Drive, Docs, Sheets, Contacts, Classroom and Tasks.

How the data is used

Only to carry out tasks the owner requests, such as summarising email, managing calendar events or saving course materials. The data stays on the owner's private server. It is never sold or shared with third parties, never used for advertising, and never used to train AI models.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from Google account permissions.
